## ۱. هدف این سند

این سند زمینه محصولی و اجرایی تذکار را از فایل‌های قدیمی، گفت‌وگوهای اشتراکی و وضعیت واقعی GitHub جمع‌بندی می‌کند تا ادامه پروژه بر پایه یک منبع روشن انجام شود و کاربر به پیام‌رسان فنی میان ChatGPT، Codex و GitHub تبدیل نشود.

## ۲. منابع بررسی‌شده

### منابع کارخانه

- بسته راه‌اندازی پروژه ChatGPT؛
- سیاست ثابت کارخانه افزونه‌سازی وردپرس؛
- گردش کار عملی کارخانه؛
- خلاصه تصمیم‌های گفت‌وگوی طراحی کارخانه؛
- الگوی شروع افزونه؛
- وظایف انسانی؛
- ساختار پروژه و چک‌لیست راه‌اندازی.

### منابع اختصاصی تذکار

- `decision-log.md` بارگذاری‌شده؛
- `project-status.md` بارگذاری‌شده؛
- `01-PROJECT-CHARTER.md` بارگذاری‌شده؛
- مخزن خصوصی `rahbarbakhtiari-collab/tazkar`؛
- تاریخچه commitها، Issueها، PRها، reviewها و CI؛
- دو Shared Link ارائه‌شده توسط مالک محصول.

### محدودیت بازیابی Shared Linkها

در این نوبت، ابزار وب نتوانست متن کامل دو Shared Link را به‌طور پایدار بازیابی کند: یکی به‌دلیل حجم بیش از محدودیت دریافت و دیگری به‌دلیل timeout. بنابراین هیچ ادعای جزئی که فقط به متن مشاهده‌نشده آن گفت‌وگوها متکی باشد ثبت نشده است. تصمیم‌های محصولی اصلی با فایل‌های بارگذاری‌شده و اسناد GitHub تطبیق داده شدند و وضعیت اجرایی فقط از GitHub استخراج شد.

## ۳. نتیجه تطبیق

### اطلاعات معتبر و ثابت محصول

- تذکار هسته‌ای برای تلنگرهای معتبر قرآنی و حدیثی است، نه صرفاً بانک محتوا.
- MVP یک افزونه واحد و ماژولار WordPress است.
- تولید و استخراج محتوا خارج از افزونه انجام می‌شود.
- ورودی افزونه CSV و سپس XLSX است.
- متن عربی تغییر نمی‌کند.
- تأیید علمی و انتشار از یکدیگر جدا هستند.
- انتشار خودکار محتوای واردشده ممنوع است.
- وب کانال نخست و ایتا کانال آینده است.

### اطلاعات قدیمی‌شده

فایل‌های بارگذاری‌شده پروژه را در مرحله مستندسازی مبانی نشان می‌دادند، اما GitHub اثبات می‌کند که پروژه از آن مرحله عبور کرده است:

- Sprint 0 تا 4 روی `main` ادغام شده‌اند؛
- نسخه توسعه‌ای فعلی `0.5.0-alpha.1` است؛
- Sprint 5 در Issue شماره 17 و Draft PR شماره 18 جریان دارد.

در نتیجه، فایل‌های قدیمی نباید به‌عنوان وضعیت جاری استفاده شوند.

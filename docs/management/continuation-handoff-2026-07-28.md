## ۱. هدف این سند

این سند زمینه محصولی و اجرایی تذکار را از فایل‌های قدیمی، گفت‌وگوهای اشتراکی و وضعیت واقعی GitHub جمع‌بندی می‌کند تا ادامه پروژه بر پایه یک منبع روشن انجام شود و کاربر به پیام‌رسان فنی میان ChatGPT، Codex و GitHub تبدیل نشود.

## ۲. منابع بررسی‌شده

### منابع کارخانه

- بسته راه‌اندازی پروژه ChatGPT؛
- سیاست ثابت کارخانه افزونه‌سازی وردپرس؛
- گردش کار عملی کارخانه؛
- خلاصه تصمیم‌های گفت‌وگوی طراحی کارخانه؛
- الگوی شروع افزونه؛
- وظایف انسانی؛
- ساختار پروژه و چک‌لیست راه‌اندازی.

### منابع اختصاصی تذکار

- `decision-log.md` بارگذاری‌شده؛
- `project-status.md` بارگذاری‌شده؛
- `01-PROJECT-CHARTER.md` بارگذاری‌شده؛
- مخزن خصوصی `rahbarbakhtiari-collab/tazkar`؛
- تاریخچه commitها، Issueها، PRها، reviewها و CI؛
- دو Shared Link ارائه‌شده توسط مالک محصول.

### منابع رسمی نسخه WordPress

در ۲۰۲۶/۰۷/۲۸، آرشیو انتشار و خبر رسمی WordPress.org بررسی شد. نتیجه:

- آخرین نسخه پایدار رسمی: `7.0.2`؛
- تاریخ انتشار: ۲۰۲۶/۰۷/۱۷؛
- شاخه `7.1` در وضعیت Beta است و برای Production یا حداقل پشتیبانی پروژه استفاده نمی‌شود.

جزئیات و روش کنترل در `docs/management/WORDPRESS-VERSION-BASELINE.md` ثبت شده است.

### محدودیت بازیابی Shared Linkها

در نوبت نخست، ابزار وب نتوانست متن کامل دو Shared Link را به‌طور پایدار بازیابی کند. بنابراین هیچ ادعای جزئی که فقط به متن مشاهده‌نشده آن گفت‌وگوها متکی باشد ثبت نشده است. تصمیم‌های محصولی اصلی با فایل‌های بارگذاری‌شده و اسناد GitHub تطبیق داده شدند و وضعیت اجرایی فقط از GitHub استخراج شد.

## ۳. نتیجه تطبیق

### اطلاعات معتبر و ثابت محصول

- تذکار هسته‌ای برای تلنگرهای معتبر قرآنی و حدیثی است، نه صرفاً بانک محتوا.
- MVP یک افزونه واحد و ماژولار WordPress است.
- تولید و استخراج محتوا خارج از افزونه انجام می‌شود.
- ورودی افزونه CSV و سپس XLSX است.
- متن عربی تغییر نمی‌کند.
- تأیید علمی و انتشار از یکدیگر جدا هستند.
- انتشار خودکار محتوای واردشده ممنوع است.
- وب کانال نخست و ایتا کانال آینده است.

### اطلاعات قدیمی‌شده

فایل‌های بارگذاری‌شده پروژه را در مرحله مستندسازی مبانی نشان می‌دادند، اما GitHub اثبات می‌کند که پروژه از آن مرحله عبور کرده است:

- Sprint 0 تا 4 روی `main` ادغام شده‌اند؛
- نسخه توسعه‌ای فعلی `0.5.0-alpha.1` است؛
- Sprint 5 در Issue شماره 17 و Draft PR شماره 18 جریان دارد.

در نتیجه، فایل‌های قدیمی نباید به‌عنوان وضعیت جاری استفاده شوند.

## ۴. تصمیم‌های تطبیقی

### ALN-001 — تقدم شواهد معتبر و تصمیم جدیدتر

- **وضعیت:** فعال
- **تصمیم:** سیاست پروژه باید با تصمیم صریح و جدید مالک محصول و اطلاعات رسمی وابسته به زمان هماهنگ شود.
- **پیامد:** اطلاعات نسخه WordPress پیش از ثبت از WordPress.org راستی‌آزمایی می‌شود.

### ALN-002 — سطح پروژه

- **وضعیت:** فعال
- **تصمیم:** تذکار در سطح `critical` اجرا می‌شود.
- **دلیل:** حفظ متن دینی، import گروهی، migration، rollback، انتشار عمومی و داده کاربر.

### ALN-003 — منبع حقیقت اجرایی

- **وضعیت:** فعال
- **تصمیم:** `main`، PR فعال و CI مخزن GitHub منبع حقیقت وضعیت فنی هستند.
- **پیامد:** گزارش‌های قدیمی فقط زمینه تاریخی‌اند.

### ALN-004 — تکمیل Sprint 5 بدون گسترش دامنه

- **وضعیت:** فعال
- **تصمیم:** PR شماره 18 باید فقط دامنه Issue شماره 17 را کامل کند.
- **پیامد:** رابط ویرایش ساختاریافته و ستون‌های مدیریت در Issueهای 13 و 14 باقی می‌مانند و وارد Sprint 5 نمی‌شوند.

### ALN-005 — خط مبنای WordPress 7.2

- **وضعیت:** منسوخ
- **تصمیم سابق:** ارجاع‌های `Requires at least: 6.8` و WordPress `7.0.2` با WordPress `7.2` جایگزین شوند.
- **علت منسوخ‌شدن:** نسخه `7.2` منتشر نشده و آخرین نسخه پایدار رسمی در تاریخ بررسی `7.0.2` است.
- **پیامد:** هر Issue، PR یا سندی که به ALN-005 استناد می‌کند باید مطابق ALN-007 اصلاح شود.

### ALN-006 — ادامه فنی از طریق PR موجود

- **وضعیت:** فعال
- **تصمیم:** به‌جای ایجاد مسیر فنی موازی، ادامه Sprint 5 از PR شماره 18 انجام می‌شود.
- **پیامد:** شاخه PR باید پس از ادغام اصلاحات اسنادی با `main` همگام شود.

### ALN-007 — خط مبنای صحیح WordPress

- **وضعیت:** فعال
- **تاریخ:** ۲۰۲۶/۰۷/۲۸
- **تصمیم:** حداقل و نسخه آزمون‌شده WordPress برای تذکار `7.0.2` است.
- **منبع:** آرشیو انتشار و اعلام رسمی WordPress.org در ۲۰۲۶/۰۷/۱۷.
- **پیامدها:**
  - `7.1 Beta` و نسخه‌های پیش‌انتشار معیار Production نیستند؛
  - کد سازگاری برای WordPress پایین‌تر از `7.0.2` ایجاد نمی‌شود؛
  - افزایش نسخه پایه فقط پس از انتشار رسمی و اصلاح مقدم اسناد، Issueها، CI و آزمون‌ها انجام می‌شود؛
  - ارجاع‌های `7.2` باید پیش از ادامه اجرای Sprint 5 حذف شوند.

## ۷. وظیفه انسانی فعلی

مالک محصول اصلاح نسخه WordPress را صریحاً اعلام و تغییر اسناد را تأیید کرده است. اقدام انسانی دیگری برای این اصلاح لازم نیست.

تنها موارد توقف آینده:

- نیاز به Secret یا حساب؛
- هزینه یا خرید؛
- تغییر Production یا حذف برگشت‌ناپذیر؛
- تعارض واقعی محصول یا تصمیم علمی/دینی؛
- پذیرش آگاهانه خطر امنیتی یا حقوقی مهم.

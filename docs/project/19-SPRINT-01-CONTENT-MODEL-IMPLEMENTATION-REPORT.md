# گزارش پیاده‌سازی Sprint 1 — مدل محتوا

**نسخه افزونه:** `0.2.0-alpha.1`  
**وضعیت:** نامزد بررسی خودکار CI

## پیاده‌سازی

- ثبت CPT با شناسه `tazkar_item`؛
- ثبت taxonomyهای `tazkar_topic` و `tazkar_tag`؛
- ثبت ۲۹ فیلد پایدار قرارداد داده ۱٫۱ به‌صورت post meta؛
- allowlist صریح برای metaهای عمومی REST؛
- مخفی‌ماندن batch، confidence، review، import و hash داخلی از REST عمومی؛
- حفظ عین رشته عربی بدون trim یا normalization؛
- نگهداری SHA-256 رشته عربی ذخیره‌شده؛
- بازگرداندن `approved` به `needs_recheck` پس از تغییر فیلد حساس؛
- عدم تغییر وضعیت پس از ویرایش فیلد غیرحساس؛
- عدم استفاده از `post_content` برای HTML نمایشی.

## آزمون‌ها

- تست واحد تنظیمات CPT و taxonomy؛
- تست واحد schema و allowlist متا؛
- تست حفظ Unicode و hash؛
- تست گذار وضعیت فیلد حساس؛
- smoke واقعی WordPress/MySQL برای ثبت، ذخیره و تغییر محتوا؛
- حفظ آزمون‌های Sprint صفر.

## خارج از محدوده

درون‌ریز، تشخیص تکرار، صف بازبینی، قالب عمومی و تعامل کاربر در این Sprint پیاده‌سازی نشده‌اند.

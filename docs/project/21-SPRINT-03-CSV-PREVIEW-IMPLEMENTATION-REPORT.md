# گزارش پیاده‌سازی Sprint 3 — پیش‌نمایش امن CSV

**نسخه افزونه:** `0.4.0-alpha.1`  
**وضعیت:** نامزد بررسی خودکار CI

## پیاده‌سازی

- صفحه مدیریت «تذکار ← پیش‌نمایش CSV»؛
- کنترل capability با `import_tazkar_items`؛
- nonce اختصاصی درخواست POST؛
- پذیرش فقط فایل `.csv` با MIME مجاز؛
- کنترل واقعی اندازه فایل تا ۱۰ مگابایت؛
- خواندن CSV با escape صریح و پشتیبانی UTF-8 BOM؛
- محدودیت ۵۰۰ ردیف و ۶۰ ستون؛
- رد UTF-8 نامعتبر، فایل خالی و محدودیت‌های منابع؛
- نگاشت ستون‌ها بر اساس نام، مستقل از ترتیب؛
- اتصال مستقیم به validator قرارداد داده Sprint 2؛
- گزارش خطا و هشدار برای هر ردیف؛
- حفظ سلول‌های فرمول‌نما به‌صورت متن و ثبت هشدار؛
- نمایش escape‌شده خروجی؛
- عدم ذخیره فایل، post، batch یا import row.

## آزمون‌ها

- BOM، comma و newline داخل سلول نقل‌قول‌شده؛
- حفظ دقیق متن عربی؛
- UTF-8 نامعتبر؛
- فایل خالی؛
- بیشینه ردیف و ستون؛
- اختلاف تعداد سلول و header؛
- فرمول‌نما؛
- جابه‌جایی ترتیب ۳۵ ستون؛
- پسوند، MIME، upload origin و اندازه؛
- capability و nonce صفحه مدیریت؛
- regression واقعی WordPress/MySQL با اثبات عدم ایجاد post یا رکورد import.

## خارج از محدوده

اجرای import، ساخت Draft، ذخیره batch، duplicate detection، resume، rollback، XLSX و پردازش chunked هنوز پیاده‌سازی نشده‌اند.

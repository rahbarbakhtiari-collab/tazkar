# پذیرش انسانی Release Candidate

**شناسه:** `docs/18-RELEASE-CANDIDATE-HUMAN-ACCEPTANCE.md`  
**نسخه:** ۱٫۰  
**وضعیت:** فعال، فقط در پایان MVP/RC

## زمان اجرا

این سند در Sprintها و PRهای میانی اجرا نمی‌شود. فقط وقتی Release Agent یک نسخه RC با CI کامل سبز تولید کرد، آزمون انسانی آغاز می‌شود.

## ورودی آزمون

- ZIP تولیدشده توسط workflow رسمی RC؛
- SHA-256؛
- commit و tag؛
- گزارش checkها؛
- فهرست تغییرات؛
- داده نمونه کنترل‌شده.

## حوزه پذیرش

1. نصب و فعال‌سازی؛
2. upgrade و حفظ داده؛
3. مسیر کامل تولید/ورود/بازبینی/انتشار MVP؛
4. فهم رابط بدون راهنمای توسعه‌دهنده؛
5. نمایش RTL و موبایل؛
6. بازخورد، علاقه‌مندی و حریم خصوصی؛
7. کیفیت تجربه و خطاهای غیرقابل کشف ماشینی؛
8. تأیید علمی نمونه محتوای دینی.

## نتیجه

- `ACCEPT`: مجاز به انتشار Beta/Stable؛
- `REJECT`: Issueهای اصلاحی تولید می‌شوند و چرخه خودکار دوباره اجرا می‌شود؛
- `BLOCKED`: تصمیم مدیریتی یا علمی لازم است.

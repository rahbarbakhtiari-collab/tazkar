# گزارش پیاده‌سازی Sprint 2 — validator قرارداد داده

**نسخه افزونه:** `0.3.0-alpha.1`  
**نسخه قرارداد:** `1.1`  
**وضعیت:** نامزد بررسی خودکار CI

## پیاده‌سازی

- تعریف دقیق ۳۵ ستون شناخته‌شده؛
- اعتبارسنجی header مستقل از ترتیب ستون‌ها؛
- گزارش ستون الزامی مفقود، ستون تکراری و ستون ناشناخته؛
- اعتبارسنجی row بدون تغییر داده ورودی؛
- کدهای خطای ثابت برای استفاده importer و UI آینده؛
- تفکیک خطای مانع ورود از هشدار قابل تصمیم؛
- قواعد شرطی قرآن و حدیث؛
- محدودیت enum، طول، فهرست، اسلاگ و متن؛
- کنترل انتخاب `source_corrected` از `source_original`؛
- کنترل خالی‌بودن `wp_post_id` پیش از ورود؛
- تشخیص `record_id` تکراری در batch؛
- حفظ عین رشته عربی در نتیجه اعتبارسنجی.

## آزمون‌ها

- fixture معتبر قرآن؛
- fixture معتبر حدیث؛
- fixture نامعتبر چندقاعده‌ای؛
- تست header با ترتیب متفاوت؛
- تست تمام خانواده‌های خطای مانع؛
- تست تمام خانواده‌های هشدار مصوب؛
- تست شناسه تکراری روی همه ردیف‌های درگیر؛
- حفظ آزمون واقعی Sprint 1 روی WordPress/MySQL.

## خارج از محدوده

خواندن CSV/XLSX، upload، preview، ساخت post، rollback و تشخیص تکرار محتوایی هنوز پیاده‌سازی نشده‌اند.

# Runbook توسعه عامل‌محور تذکار

## نقش‌ها

### Planner
Issue آماده را به Task قابل آزمون تبدیل می‌کند. حق توسعه کد ندارد.

### Implementer
فقط Task مصوب را پیاده می‌کند، تست می‌نویسد و Draft PR می‌سازد.

### Test Agent
سناریوهای منفی و regression را مستقل از پیاده‌ساز می‌سازد.

### Architecture Reviewer
انطباق با اسناد، قرارداد داده و تصمیم‌های فعال را بررسی می‌کند.

### Security Reviewer
ورودی، دسترسی، nonce، escaping، SQL، فایل و privacy را بررسی می‌کند.

### CI Repair Agent
فقط خطاهای عینی checkها را رفع می‌کند و حداکثر سه دور مجاز است.

### Release Agent
ZIP، checksum، manifest و گزارش RC را تولید می‌کند.

## قرارداد خروجی عامل

هر عامل باید این موارد را در Issue یا PR ثبت کند:

- کار انجام‌شده؛
- فایل‌های تغییرکرده؛
- فرمان‌ها و تست‌های اجراشده؛
- نتایج واقعی؛
- خطر باقی‌مانده؛
- وضعیت نهایی: `PASS` یا `BLOCKED`؛
- Task بعدی پیشنهادی، بدون اجرای خارج از دامنه.

## توقف

عامل فقط در موارد زیر توقف و ارجاع می‌دهد:

- تعارض اسناد؛
- نیاز به secret یا دسترسی؛
- تغییر محصول یا قرارداد؛
- تصمیم دینی/علمی؛
- سه شکست متوالی یکسان؛
- خطر حذف یا افشای داده که آزمون قابل اطمینان ندارد.

زیرساخت افزونه تذکار برای مدیریت تلنگرهای قرآن و حدیث.

== Description ==

این نسخه فقط اسکلت Sprint صفر است و هنوز قابلیت ورود محتوا یا نمایش عمومی ندارد.

== Installation ==

1. فایل ZIP را از بخش افزونه‌ها نصب کنید.
2. افزونه را برای هر سایت جداگانه فعال کنید.
3. از منوی «تذکار» وضعیت زیرساخت را بررسی کنید.
